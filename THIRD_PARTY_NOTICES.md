# Third-Party Notices and Data Review Gate

This repository includes or derives from third-party models and datasets. Their terms are separate from the MIT and CC BY 4.0 licenses for original project code and documentation.

Before public release, confirm redistribution rights, preserve source notices, and add the exact citations and license statements for:

- Recon1 and the adapted Recon1 teaching model
- Human1-derived subsystem mappings, if redistributed
- DepMap expression and identifiers
- GTEx breast expression
- Jain CORE metabolomics and associated metadata
- Keibler HMEC measurements and associated metadata
- Any other supplied model, dataset, article, or source-format file

The current public staging tree intentionally excludes raw source files, article PDFs, spreadsheets, and preprocessing scripts. Treated CSVs and model files still require a final redistribution and attribution review before pushing to GitHub.
